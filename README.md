# FNAFRoomCode
This is my second front-end website, created as part of a high-school computer science course.
The goal of this project was to learn core web-development concepts, practice JavaScript problem-solving, and follow an iterative design process from planning → development → testing → reflection.

The project includes:

- Custom UI built with HTML and CSS
- Dynamic interaction powered by JavaScript
- Fully documented iterative process (included in /docs)
- UX testing and feedback results (also in /docs)
